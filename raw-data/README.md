# Raw Benchmark Data

Store original captures, laser/tape measurements, device metadata, and consumer-app exports here or in the separately submitted reproduction bundle. Do not commit private property data without permission.

Required metadata per capture:

- capture id and tier
- device model and OS
- camera/app name and version
- timestamps and capture duration
- room list and room adjacency
- units and ground-truth instrument
- operator notes about mirrors, glass, low light, furniture, or occlusion
